# gpu-architecture

CS623 (GPU Architecture) coursework.

| Folder | Contents |
|---|---|
| `assignment-1-nvbit/` | NVBit-based dynamic instrumentation tools (pc_trace, mem_trace, control divergence, cache simulation) plus `mem_div/` sources |
| `assignment-2/` | CUDA problems 1-3, report (LaTeX/PDF), profiling and timing data. See `HOW_TO_RUN.md` |
| `assignment-3/` | GPU device/driver work: `chdev`, `pio`, `mmio`, `mock`, `accel_release`. See `cheatsheet.md` |

Large generated files (traces, tarballs, binaries, test data) are excluded via `.gitignore`.
